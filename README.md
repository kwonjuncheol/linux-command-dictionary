- # 🐧 Linux 명령어 사전

  > **시스템프로그래밍(B) 중간고사 과제**  
  > 1~7주차 수업에서 배운 명령어와 추가 명령어를 포함하여 총 77개의 리눅스 명령어를 담은 웹 사전입니다.

  ---

  ## 🔗 사전 링크
  - [Linux 명령어 사전 바로가기](https://kwonjuncheol.github.io/linux-command-dictionary/)

  ---

  ## ✨ 주요 기능
  - **키워드 검색**: 명령어 이름 및 설명에 포함된 단어로 빠르게 검색 가능합니다.
  - **카테고리 구분**: 파일 및 디렉토리 관리, 시스템 관리 및 정보, 프로세스 관리, 네트워크, 권한 및 소유권, 텍스트 처리, 셸 스크립트 제어의 7가지 카테고리로 필터링할 수 있습니다.
  - **명령어 비교하기**: 카드/목록에서 2개의 명령어를 선택하여 한 화면에서 비교할 수 있습니다.
  - **알파벳순 정렬**: 전체 명령어가 알파벳순(A-Z)으로 자동 정렬되어 탐색 편의성을 제공합니다.
  - **유연한 데이터 확장성**: `commands.json` 데이터 구조를 통해 새로운 명령어 간편 추가 가능합니다.

  ---

  ## 👥 팀원 및 역할
  - **정혜린**: 프로젝트 협업 공간 구축(notion), 4주 수업 내용 정리
  - **임선희**: 프로토타입 구상 및 3,5주 수업 내용 정리
  - **장동현**: 사용성 테스트 및 데이터 표준화, 6,7주 수업 내용 정리
  - **권준철**: `commands.json`,`index.html`구현 및 GitHub Pages 배포, 보고서 작성
