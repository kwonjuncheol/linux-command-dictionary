- # 🐧 Linux 명령어 사전

  > **시스템프로그래밍(B) 중간고사 과제**  
  > 수업 시간에 배운 명령어와 추가 명령어를 포함하여 총 50개의 리눅스 명령어를 담은 웹 사전입니다.

  ---

  ## 🔗 사전 링크
  - [Linux 명령어 사전 바로가기](https://kwonjuncheol.github.io/linux-command-dictionary/)

  ---

  ## ✨ 주요 기능
  - **키워드 검색**: 명령어 이름 및 설명에 포함된 단어로 빠르게 검색 가능합니다.
  - **카테고리 구분**: 파일/디렉토리, 시스템, 프로세스, 네트워크, 권한, 텍스트 처리 버튼을 눌러 필터링 할 수 있습니다.
  - **명령어 비교하기**: 카드/목록에서 2개의 명령어를 선택하여 한 화면에서 비교할 수 있습니다.
  - **알파벳순 정렬**: 전체 명령어가 알파벳순(A-Z)으로 자동 정렬되어 탐색 편의성을 제공합니다.
  - **유연한 데이터 확장성**: `commands.json` 데이터 구조를 통해 새로운 명령어 간편 추가 가능합니다.

  ---

  ## 👥 팀원 및 역할
  - **정혜린**: 프로젝트 협업 공간(Notion) 구축, 수업 핵심 내용 및 명령어 데이터 총괄 정리
  - **임선희**: 수업 내용 상세 분석 및 설명 정립, 자료 통합 및 최종 제출 보고서 작성
  - **장동현**: 명령어 옵션 및 예시 구문 교차 검증, 사용성 테스트 및 데이터 표준화
  - **권준철**: `commands.json`,`index.html`구현 및 GitHub Pages 배포
